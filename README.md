# GB Cam Formatter

Bulk-format Game Boy Camera photos in your browser.

## Features

- Add EXIF timestamps to images based on filename numbers
- Trim Game Boy Printer borders
- Preview and browse before exporting
- Download everything as a ZIP

## Usage

1. Drop your numbered images (e.g. `000283.png`)
2. Pick a date range
3. Adjust border trim if needed
4. Download the ZIP

Runs entirely client-side. No uploads, no server.

## Deploy

Pushes to `main` auto-deploy to GitHub Pages via Actions.
